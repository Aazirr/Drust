# Drust UI Rework Assets

This folder contains the tactical asset pack described in `docs/ui-rework-plan.md`.

Structure:

- `brand/` - wordmark, favicon, loading splash
- `backgrounds/` - map tile, grid, grain, scan lines, radar noise
- `icons/` - status, nav, action, and utility icons
- `markers/` - map markers and entity icons
- `operation/` - timer ring and operation hero art
- `ornaments/` - corner brackets and small display accents
- `manifest.json` - quick lookup for the web app
- `ui-rework.css` - helper classes for the decorative-only assets

All assets are pure SVG or CSS and are intended to be served directly by the web app.
